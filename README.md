# Système de placement — Frontend

Application React du système de placement en ligne du Cégep.

L’interface s’adapte au rôle de l’utilisateur. Les étudiants peuvent rechercher des offres, soumettre et suivre leurs candidatures ou leurs demandes de stage. Les employeurs gèrent leur entreprise, leurs offres et les candidatures reçues. Les administrateurs gèrent les utilisateurs, les cégeps et les domaines d’études.

Le frontend communique avec l’API du projet backend.

## Technologies

- React
- Vite
- React Router
- Axios
- CSS

## Installation

```bash
npm install
npm run dev
```

## Configuration

Copier `.env.example` vers `.env`, puis ajuster l’URL de l’API backend au besoin.
